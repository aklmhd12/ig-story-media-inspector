IG Story Media Inspector

Paste a Story or Highlight link, open it in your own Instagram session, then scan the media that Instagram actually delivered to the browser — images, videos, posters, CDN resources, embedded JSON, and live API responses.

What it checks automatically

Visible images & videoDOM images, srcset, videos, video posters and source elements.
Network resourcesPerformance entries and live resource requests from Instagram/CDN hosts.
Embedded metadataMedia URLs inside page scripts, JSON and HTML, including escaped CDN links.
Live API responsesFuture Fetch/XHR JSON responses are scanned for image/video URLs while the panel is open.
Target Story matchingStory media IDs found in shared URLs are used to boost candidates discovered near matching data.
Preview & exportOpen, copy or download candidates and export a JSON report.

Important limitation

If Instagram sends the clean uploaded photo separately, this tool can surface it. If Instagram sends only one already-composited image/video with the sticker, reaction or overlay baked in, the hidden original pixels are not present in the browser response.

This tool does not use AI to invent hidden faces. A “clean” result is only treated as real when it exists as an actual media resource delivered by Instagram to your authorized session.

GitHub Pages is a different web origin from Instagram, so a static site cannot safely read private Instagram responses or cookies directly. That is why the inspector runs on the official Instagram page instead of asking for your password.

Install as an app (optional)

This site is a PWA. On supported Android browsers, choose Add to Home screen / Install app for quicker access. The Instagram inspection itself still runs through the bookmark on the authorized Instagram page.
